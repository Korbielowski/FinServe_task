# FinServe - AI and Automation Opportunities

## Installation

```bash
git clone https://github.com/Korbielowski/FinServe_task.git
cd FinServe_task/
uv sync
```

## Usage

```bash
cd src/
uv run streamlit run app.py
```

## Configuration
```dotenv
OPENAI_API_KEY="sk-..."
SENDER_EMAIL="your.email@gmail.com"
SENDER_PASSWORD="your-app-password"
```
